# MorphSDF

<img width="800" height="501" alt="DynamicBakeSDF" src="https://github.com/user-attachments/assets/08de3c09-bdd3-447c-bb61-aeba9dd5888f" />

Supported dynamically generate SDFs from SkinnedMesh and other objects.

## Performance
Tested with a 500^3 voxel volume, 13k triangle mesh

RTX4080 Laptop 30ms

## Requirements
Unity 6000.33f1
Async compute and Awaitable supported on target platform

## Installation

1. Open the Unity Package Manager
2. Click the + button
3. Select "Add package from git URL..."
4. Paste the following URL
```
https://github.com/DreamTapir/MorphSDF.git?path=Packages/MorphSDF
```
